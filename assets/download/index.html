What the app is

  • A window onto fluxdev.org, so it is always the latest version: there is nothing to update, ever.
  • Your campaigns, characters and sign-in are the same as on the website, on any device.
  • Fullscreen and borderless windows, and it remembers how big you left it.
  • It needs an internet connection. If the site can't be reached it says so and lets you try again.

Installing on Windows

  1. Download the zip and unzip it anywhere (Right-click, Extract All).
  2. Open the folder and run Pokemon D&D Companion.exe.
  3. The first time, Windows may say Windows protected your PC because the app isn't signed yet. Choose More info, then Run anyway.

On a phone or tablet you don't need an app: open the website and use Add to Home Screen.
