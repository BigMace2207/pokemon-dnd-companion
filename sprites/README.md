# Sprites

All Pokémon art in this folder is provided by [PokeAPI](https://pokeapi.co)
(`export_sprites.py`) and originates from Nintendo, Game Freak and The Pokémon
Company. Trainer portraits come from Pokémon Showdown
(`export_trainer_sprites.py`). They are included for use inside this unofficial
fan app only and remain the property of their owners.
